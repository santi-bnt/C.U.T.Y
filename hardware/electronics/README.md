# C.U.T.Y Electronics

KiCad is the PCB source-of-truth area. `kicad/` will hold native projects/boards; `schematics/` holds documented schematic exports; `datasheets/` holds reference documents with their component/version identity.

Plan areas for STM32 control PCB, Raspberry UART connection, servo connectors, IMU, and power distribution. No PCB, schematic, pin assignment, or power design is implemented now. Coordinate approved wiring, rails, and grounding with [wiring](../../docs/wiring.md) before hardware integration.
