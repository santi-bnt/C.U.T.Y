# Vision

Camera → face detector (YuNet, Haar fallback) → face tracker → normalized target (X/Y, confidence). See the [vision module](../raspberry/src/cuty/vision/README.md).

Implemented: Raspberry Pi camera or USB webcam capture, face detection, closest-person selection with stickiness, smoothing, lost-target handling and camera reconnection. The touchscreen face uses the target for the pupils. A consent-based local SFace enrollment/matching path, explicit still-image Gemini description, and an opt-in physical PAN-follow path through the motion socket are implemented in software. The SFace model is not shipped, Pi OpenCV compatibility and biometric thresholds require local setup/calibration, and these newer flows have not been validated on the robot. Camera initialization has previously been observed on the Pi with an OV5647; this does not verify the new voice/recognition workflow. Vision produces no PWM and has no direct UART access. See [voice vision and privacy setup](face-vision.md) and the [physical validation guide](robot-validation.md).
