# Vision

Camera → face detector (YuNet, Haar fallback) → face tracker → normalized target (X/Y, confidence). See the [vision module](../raspberry/src/cuty/vision/README.md).

Implemented: Raspberry Pi camera or USB webcam capture, face detection, closest-person selection with stickiness, smoothing, lost-target handling and camera reconnection. The touchscreen face uses the target for the pupils. A consent-based local SFace enrollment/matching path and explicit still-image Gemini description are implemented in software through the existing FaceTracker camera and a private local socket. The SFace model is not shipped, Pi OpenCV compatibility and biometric thresholds require local setup/calibration, and these new flows have not been validated on the robot. Camera initialization has previously been observed on the Pi with an OV5647; this does not verify the new voice/recognition workflow. Vision produces no PWM and has no direct servo access. See [voice vision and privacy setup](face-vision.md). Physical head movement through STM32F401 remains future work.
