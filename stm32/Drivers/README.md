# STM32 Drivers

Vendored CMSIS headers only: ARM CMSIS 6.1 core/RTOS2 headers and ST's
`cmsis_device_f4` (STM32F401xC register definitions, startup file and system file).
Versions and licenses are listed in [THIRD_PARTY.md](../THIRD_PARTY.md). The board
drivers themselves live in `Core/Src/board_f401.c`.
